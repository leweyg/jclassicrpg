# game_interactions

[docs](https://github.com/leweyg/jclassicrpg/blob/main/docs/README.md) · [game](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/README.md)

Interaction content binds immutable catalogs and scene anchors to persistent player state. Concrete shipped data and `interactions/format.js` govern executable fields; the detailed examples also preserve extension contracts and migration rationale.

- [interaction_contracts](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/contracts.md) — layers, identity, scene integration, predicates, and transactions.
- [game_missions](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/missions.md) — objectives, story graph, event progress, and authoring integration.
- [game_actors](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/actors.md) — legacy identity, safe anchors, dialogue, and goal allocation.
- [game_inventory](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/inventory.md) — item provenance, deterministic loot, containers, and transfers.
- [game_puzzles](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/puzzles.md) — shrines, circuits, maze generators, and solvability.
- [game_saves](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/saves.md) — delta shape and versioned migration.
