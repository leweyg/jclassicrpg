# game_world

[docs](https://github.com/leweyg/jclassicrpg/blob/main/docs/README.md) · [game](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/README.md)

The world is reconstructed offline from saved evidence and served as immutable scenes. Keep geometry, rendering, navigation, and saved state separate.

- [world_evidence](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/evidence.md) — legacy provenance, extraction schemas, and owner reconciliation.
- [world_generation](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/generation.md) — Java determinism, districts, buildings, and compatibility choices.
- [world_settlements](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/settlements.md) — capital identities and cultural hierarchy.
- [world_mazes](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/mazes.md) — recursive division bytes and the three-level shell.
- [world_caves](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/caves.md) — natural occupancy and cave entrances.
- [world_navigation](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/navigation.md) — layered graphs and portals.
- [city_rendering](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/rendering/city.md) — semantic geometry to calibrated mesh instances.
- [game_streaming](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/runtime/streaming.md) — delivery, cache, and slot lifecycle.
- [world_checks](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/testing/world.md) — Java fixtures and geometry review.
