# Docs

Current guidance, detailed design contracts, and recorded evidence for The Spiral Grid. [index](https://github.com/leweyg/jclassicrpg/blob/main/README.md) provides the project overview. Commands and code paths assume the repository root.

| Subject | Contents |
| --- | --- |
| [fiction](https://github.com/leweyg/jclassicrpg/blob/main/docs/fiction/README.md) | Theory, layers, archetypes, and detailed cultures. |
| [story_plot](https://github.com/leweyg/jclassicrpg/blob/main/docs/story/README.md) | Narrative plot with stable gameplay bindings. |
| [story_authoring](https://github.com/leweyg/jclassicrpg/blob/main/docs/story/authoring/README.md) | Pacing, character direction, regional arcs, and complete dialogue treatments. |
| [game](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/README.md) | Play, mechanics, systems, and build entry points. |
| [game_world](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/world/README.md) | Source evidence and deterministic world construction. |
| [game_interactions](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interactions/README.md) | Data contracts, objectives, actors, puzzles, items, and saves. |
| [game_runtime](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/runtime/README.md) | Browser runtime and bounded streaming. |
| [game_rendering](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/rendering/README.md) | Mesh compilation, materials, calibration, and particles. |
| [game_interface](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/interface/README.md) | Dialogue, map, journal, and page behavior. |
| [game_development](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/development/README.md) | Compiler workflow, source map, ownership, and release gates. |
| [game_testing](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/testing/README.md) | Active procedures, acceptance contracts, and historical results. |

Unique material from the former archive is incorporated into these subject guides. Duplicate opening briefs and repeated review passages are consolidated. Live schemas and catalogs govern runtime data; illustrative designs and earlier revisions are identified where their behavior differs. Dated measurements are kept in [test_results](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/testing/results.md). Evidence files remain in `docs/*-evidence/` so the original artifacts stay available.
