# older_v1

Historical design briefs, implementation notes, and verification reports retained from before the Fiction / Story / Game documentation organization. `v1` labels this documentation archive; individual reports may describe web-v1 or web-v2 game builds. Recorded checks and proposed behavior retain their original scope.

Current entry points: [fiction](https://github.com/leweyg/jclassicrpg/blob/main/docs/fiction/README.md), [story_plot](https://github.com/leweyg/jclassicrpg/blob/main/docs/story/README.md#story_plot), [game](https://github.com/leweyg/jclassicrpg/blob/main/docs/game/README.md).

Original root-level documents are under `root/` to preserve both versions of the story brief and interaction review. Evidence assets remain in their existing `docs/*-evidence/` directories; links below and within reports point to them. Commands and code paths in historical documents assume the repository root.
